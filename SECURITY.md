# Security policy

Report vulnerabilities in Leverprice or any of its SDKs to **security@leverprice.com**. Please do not open a public issue.

Include the affected repository or service, the version, steps to reproduce and the impact you observed. We acknowledge every report, keep you informed while we work on a fix, and credit you in the release notes unless you prefer otherwise.

## Scope

- The SDKs in [github.com/leverprice](https://github.com/leverprice)
- leverprice.com and its subdomains

## Supported versions

Security fixes ship in the latest release of each SDK.
